# Тренажёр итальянских артиклей 🇮🇹

Локальное и онлайн веб-приложение для отработки итальянских артиклей (уровни A1–A2).

🌐 **Онлайн версия**: [allenatore-italiano.onrender.com](https://allenatore-italiano.onrender.com)

---

## 🚀 Как запустить локально

Убедитесь, что у вас установлен **Node.js**.

1. Откройте терминал в папке проекта `allenatore italiano`.
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Откройте файл `.env`. Вставьте ваш ключ [DeepL API](https://www.deepl.com/pro-api) вместо заглушки.
4. Запустите сервер:
   ```bash
   npm start
   ```
5. Откройте в браузере: [http://localhost:3000](http://localhost:3000)

## 💡 Как пользоваться

### Фильтры
Вверху страницы находятся два выпадающих списка:
- **Уровень**: только A1 или A1+A2 вместе.
- **Тип артиклей**: все, только определённые (il/la/lo...) или только неопределённые (un/una/uno...).
При изменении фильтра сразу загружается новое предложение по выбранным параметрам.

### Работа с предложением
- В предложении есть одно или несколько пустых полей `___`.
- Впишите правильный итальянский артикль в каждое поле.
- Апострофы (`l'`, `un'`) поддерживаются. Регистр не важен.
- Нажмите **Enter** в последнем поле — это то же самое, что нажать «Проверить».

### Перевод слов по клику / наведению
- На **компьютере**: наведите мышку на любое слово в предложении — появится всплывающая подсказка с переводом на русский.
- На **телефоне**: нажмите (тапните) на любое слово — появится перевод. Тапните на то же слово или в другое место — подсказка закроется.
- Переводы кэшируются: каждое слово переводится через DeepL только один раз за сессию.

### Кнопка «Проверить»
- Нажмите после того, как заполните все поля.
- Правильные ответы подсветятся **зелёным** и заблокируются.
- Неправильные — **красным**. Вы можете исправить их и нажать «Проверить» снова.
- Когда все поля правильные, показываются правильные артикли и счётчик пополняется.

### Кнопка «Перевод предложения»
- Доступна в любой момент, даже до проверки.
- Показывает полное итальянское предложение (с артиклями) — удобно для тренировки произношения вслух.
- Ниже выводится перевод всего предложения на русский язык через DeepL.

### Кнопка «Следующее»
- Загружает случайное предложение согласно выбранным фильтрам.
- С вероятностью ~35% попадаются предложения с несколькими пропусками.

### Статистика
Внизу экрана — статистика текущей сессии (сбрасывается при перезагрузке):
- **Попыток** — сколько раз нажималась кнопка «Проверить».
- **Правильно** — сколько раз все поля были заполнены верно с первого раза.
- **Точность** — процент правильных ответов.

### Кнопка справки (?)
Кнопка вверху справа открывает краткое руководство прямо в приложении.

## 🔑 Переменные окружения (.env)

| Переменная | Описание |
|---|---|
| `DEEPL_API_KEY` | Ключ от DeepL API (обязателен для переводов) |
| `PORT` | Порт сервера (по умолчанию: 3000) |
