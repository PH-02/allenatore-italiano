# Инструкция по запуску и использованию тренажёра итальянских артиклей

Этот проект представляет собой локальное веб-приложение для помощи в изучении и отработке определeнных и неопределeнных итальянских артиклей (уровни A1–A2).

## 🚀 Как запустить

Убедитесь, что у вас установлен **Node.js**.

1. Откройте терминал в папке проекта `allenatore italiano`.
2. Установите необходимые зависимости, выполнив команду:
   ```bash
   npm install
   ```
3. Откройте файл `.env`. Вместо `your_deepl_api_key_here` вставьте ваш действующий ключ для [DeepL API](https://www.deepl.com/pro-api). Без него функция перевода работать не будет.
4. Запустите сервер командой:
   ```bash
   npm start
   ```
5. Откройте в вашем браузере адрес: [http://localhost:3000](http://localhost:3000)

## 💡 Как пользоваться приложением

### Основной интерфейс
- **Фильтры**: Вы можете выбрать конкретный уровень (только A1 или включая A2) и тип артиклей (все, только определённые, или только неопределённые).
- **Следующее предложение**: Загружает случайный пример согласно выбранным фильтрам. С вероятностью около 35% вам могут попасться предложения с несколькими пропусками.
- **Поле ввода**: Впишите правильный артикль в пропуск (`___`). Апострофы (например, `l'`) поддерживаются, регистр не имеет значения.

### Проверка ответов
После того как вы заполните пропуски, нажмите кнопку **Проверить** (или клавишу Enter, находясь в последнем поле).
- Если ответ **верный**, поле подсветится зелёным цветом, а счётчик правильных ответов увеличится.
- Если **есть ошибка**, поле окрасится в красный, и вы увидите текст «Неправильно». 
Ниже всегда будет показан правильный ответ.

### Перевод и произношение
Кнопка **Перевод и произношение** доступна в любой момент, даже до проверки ответа. При её нажатии:
1. Система покажет полное итальянское предложение (артикли будут подставлены в пропуски). Эту строку удобно использовать для тренировки произношения и проговаривания вслух.
2. Приложение сделает запрос к локальному серверу, который, в свою очередь, обратится к API DeepL и покажет **русский перевод** предложения.

### Статистика
Внизу экрана ведётся статистика вашей текущей сессии:
- **Попыток**: сколько всего раз вы нажимали кнопку «Проверить».
- **Правильно**: сколько раз ваши ответы были полностью точными.
- **Точность**: процент успешных ответов.
